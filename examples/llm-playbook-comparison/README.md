# LLM playbook: Fiori vs React (educational)

Open **`fiori-concepts-vs-react.html`** in a browser (double-click or `python -m http.server` from repo root and navigate under this path).

**Purpose:** Explain why **OpenUI5 XML** uses a different **contract** than **React** for the same business fields, and point to **DESIGN.md**, **SAPUI5-COMPONENTS.md**, and **ComponentSpec** JSON.

**Not a substitute** for reading the [SAPUI5 API](https://ui5.sap.com/#/api) before implementation.
